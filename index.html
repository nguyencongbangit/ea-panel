Hướng dẫn MQL4

Tích hợp EA với hệ thống bản quyền GitHub

1. URL file xác thực (dán vào MetaTrader Allowed URLs)

–

File verify.txt tự động cập nhật mỗi khi bạn thay đổi license. GitHub CDN cache tối đa 5 phút → EA bị thu hồi license sẽ dừng trong vòng 5 phút.

2. Code MQL4 — copy vào đầu file EA trước khi compile

// Đang tải...

3. Quy trình cấp license cho khách hàng

  1. Tạo license trên Dashboard → lấy License Key
  2. Thêm số tài khoản MT4 của khách vào license
  3. Sửa trong code EA: LICENSE_KEY và VERIFY_URL
  4. Compile → gửi file .ex4 cho khách
  5. Khách: Tools → Options → Expert Advisors → Allow WebRequest → thêm URL ở trên
  6. Để thu hồi từ xa: Đổi status → Inactive → EA dừng trong ≤5 phút

4. Định dạng file verify.txt

EA-F73C47-82F4AF-4A43A4|ACTIVE|2026-12-31|12345678,99999999
EA-1876FC-55E789-430CB5|ACTIVE||14683013
EA-AABBCC-DDEEFF-001122|INACTIVE||

# Cột 1: License Key
# Cột 2: ACTIVE / INACTIVE / EXPIRED
# Cột 3: Ngày hết hạn YYYY-MM-DD (để trống = Lifetime)
# Cột 4: Các MT4 ID cách nhau bởi dấu phẩy

Lưu ý bảo mật

  • GitHub PAT lưu sessionStorage — tự xóa khi đóng tab/browser
  • Mật khẩu dashboard lưu dạng SHA-256 hash trong localStorage — không thể giải mã ngược
  • Dữ liệu license lưu trên GitHub repo riêng tư của bạn — chỉ bạn và người có PAT mới đọc được
  • File verify.txt có thể public (chứa key + MT4 ID) → bảo mật bởi key khó đoán + MT4 ID cần phải được admin thêm tay
  • Không dùng PAT cho mục đích khác ngoài repo này
